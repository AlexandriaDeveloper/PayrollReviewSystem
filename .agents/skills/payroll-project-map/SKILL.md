# مهارة خريطة المشروع والذاكرة المعمارية — Payroll Project Map

## متى تستخدم هذه المهارة؟
تُستخدم هذه المهارة إلزاميًا في كل مهمة تتضمن:
1. استكشاف شجرة المشروع والتعرف على مواقع المشاريع ومسؤولياتها.
2. إضافة مشروع جديد، أو تعديل مراجع المشاريع والاعتماديات في `*.csproj`.
3. إعداد أو تعديل جداول قاعدة البيانات ومخططات الكيانات في المراحل المصرح بها.
4. إعداد تقرير اكتمال المهمة ومراجعة الـ PR؛ لضمان تحديث الذاكرة المعمارية الموحدة في `docs/PROJECT-MEMORY-AR.md`.

---

## 1. القواعد الصارمة للذاكرة المعمارية
1. **تحديث إلزامي مع كل تغيير في البنية:**
   أي PR يضيف مشروعًا، أو يغير اتجاه تبعية، أو يضيف جداول/علاقات قاعدة بيانات معتمدة، **يجب أن يتضمن تحديثًا صريحًا لملف `docs/PROJECT-MEMORY-AR.md`** يعكس التغييرات الفعلية بدقة، مع التمييز الصريح بين ما هو قيد المراجعة في `Draft PR` وما تم اعتماده ودمجه فعليًا.
2. **منع التخمين والكيانات الافتراضية:**
   ممنوع منعًا باتًا اختراع جداول أو أعمدة أو علاقات غير موجودة فعليًا في الكود المعتمد. إذا لم تكن هناك جداول، تظل الحالة:
   `STATUS: NOT_DESIGNED / NO_TABLES`.
3. **احترام أسماء المشاريع المختصرة:**
   الالتزام بالأسماء المختصرة المحددة بقرار المالك في المهمة `BOOT-001` (المرجع التنفيذي [Issue #48](https://github.com/AlexandriaDeveloper/PayrollReviewSystem/issues/48) والتكليف المرتبط [Issue #47](https://github.com/AlexandriaDeveloper/PayrollReviewSystem/issues/47)):
   - `src/core/core.csproj`
   - `src/application/application.csproj`
   - `src/infrastructure/infrastructure.csproj`
   - `src/api/api.csproj`
   - `client/`
   - `tests/unit-tests/unit-tests.csproj`
   - `tests/architecture-tests/architecture-tests.csproj`
4. **احترام حدود Clean Architecture:**
   - التبعيات تتدفق دائمًا إلى الداخل: `API -> Infrastructure & Application -> Core`.
   - `core` لا تعتمد على أي طبقة أخرى ولا تضم حزمًا خارجية.
   - `application` تعتمد على `core` فقط.
   - `infrastructure` تعتمد على `core` و `application`.

---

## 2. قائمة التحقق للوكيل قبل تقديم PR (Checklist)
- [ ] هل تم فحص مسارات التبعيات في `*.csproj` والتجميعات والتأكد من مطابقتها لـ Clean Architecture؟
- [ ] هل تم تشغيل الاختبارات المعمارية في `tests/architecture-tests` (شاملة فحص `csproj` الثابت والحالات السلبية) ونجاحها؟
- [ ] هل تم تحديث `docs/PROJECT-MEMORY-AR.md` إذا كان التعديل يمس الكيانات أو المشاريع أو التبعيات؟
- [ ] هل تم التأكد من عدم وجود بيانات حساسة أو أسرار أو سلاسل اتصال صريحة؟
- [ ] هل تم الالتزام بحالة قاعدة البيانات المعتمدة (حاليًا: `SQL Server 2014` مستهدف لاحقًا، ولا وجود لـ ORM في `BOOT-001`)؟
