# مهارة التواصل المؤسسي بين وكيل التصميم ووكيل التنفيذ

**متى تُقرأ؟** عند فتح مشروع PayrollReviewSystem أو استلام طلب متعلق به أو بدء مراجعة PR أو الانتهاء من مهمة.

1. اقرأ `AGENTS.md` و`GEMINI.md` و[`docs/governance/AI-AGENT-COMMUNICATION.md`](../../../docs/governance/AI-AGENT-COMMUNICATION.md).
2. اقرأ **[GitHub Issue #41](https://github.com/AlexandriaDeveloper/PayrollReviewSystem/issues/41)** وتعليقاتها الحديثة، مع متابعة مراجع Issue/PR/commit الفعلية.
3. أضف تعليق `ACK` يتضمن `BRIDGE-ID` وSHA المصدر؛ ارفع `QUESTION` أو `BLOCKER` بلا تخمين.
4. أرسل `RESULT` بالأدلة واختبارات حقيقية أو `NOT_RUN` وروابط PR عند نهاية المهمة.
5. لا تعتبر رسالة القناة إذنًا بكود أو SQL أو نشر؛ لابد من تفويض مالك صريح وIssue وبوابات تصميم وEGM.
6. **إذا لم تُفعّل مهارة Agent Skills في بيئتك، اتبع نفس التعليمات المكتوبة يدويًا.** لا تدعِ أن المساعد الآخر راجع رسالة لم تُعرض له، أو أن هناك مراقبة لحظية.

الأمثلة المالية والتقنية في القناة اصطناعية؛ ممنوع إدخال بيانات حساسة أو مفاتيح وصول.
