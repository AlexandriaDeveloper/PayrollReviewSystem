# حزمة تخطيط نظام مراجعة المرتبات

**الحالة: مسودات تصميم وتخطيط للمراجعة، مبنية على قاعدة العمل المعتمدة.** أعدت في 11 نوفمبر 2026 بناء على طلب المالك برومبتًا لـGemini / Antigravity وخطة شاملة وUML ومخطط قاعدة بيانات مع OOP وSOLID. المرجع المعرفي عند الإعداد `29696099d1dc75cc06dd62cf58221fdc0d7a7d29`.

## ابدأ من هنا

1. **[البرومبت الجاهز لـGemini / Antigravity](GEMINI-ANTIGRAVITY-MASTER-PROMPT-AR.md):** انسخ قسم بداية البرومبت إلى نهايته، أو اطلب من Gemini قراءة الملف وتنفيذ تكليفه.
2. **[شرح الخطة بالعربية](COMPREHENSIVE-WORK-PLAN-AR.md):** الهدف والشاشات والمراحل والحزم والصلاحيات والقرارات والاختبارات.
3. **[مخططات UML](UML-AR.md):** الكلاسات ودورة الرد والحسم والاعتماد وحالات الملاحظة والمتابعة.
4. **[مخطط قاعدة البيانات](DATABASE-DIAGRAM-AR.md):** الهوية والصرفيات والمصدر والمراجعة والفروق، مع قاموس القيود والأسئلة.
5. **[مصفوفة المتطلبات والقبول](REQUIREMENTS-AND-ACCEPTANCE-MATRIX.md):** ربط المصدر والمرحلة والرسم والاختبار المطلوب مستقبلًا.
6. **[دليل Elephant–Goldfish](EGM-REVIEW-RUNBOOK-AR.md):** تشغيل المراجعة المستقلة على البيئة الفعلية والأدلة المطلوبة.

## منزلة هذه الملفات

الخطة والرسوم مقترحات يمكن نقدها وتعديلها؛ لا تجعلها أسماء جداول أو عقود API نهائية. [قاعدة العمل](../WORKING-BASELINE-AR.md) والقرارات المعتمدة تحكمها. لا تتضمن هذه الحزمة برنامجًا أو DDL أو تفعيل نسب، ولا تدعي اكتمال دراسة المكتبة أو تشغيل ملحق Antigravity على جهاز المستخدم.

نتائج فحص الحزمة ومراجعتها تضاف في `reviews/` مع هوية النسخ والأدلة وحدودها. يجب التفريق بين مراجعة مستقلة بأداة البيئة المتاحة هنا وبين تشغيل ملحق EGM في بيئة Antigravity لاحقًا، وبين الملاحظة المقبولة والسؤال المفتوح وقرار المالك.

## نتائج فحص المسودة
[سجل المراجعات والإصلاحات وعرض الرسوم](REVIEW-AND-VERIFICATION-AR.md). النسخة المسلّمة 0.2؛ توجد 5 رسوم UML و4 رسوم ERD عرضت بأداة Mermaid CLI. المراجعات الأصلية محفوظة ضمن reviews ولا تمثل تشغيل ملحق Antigravity على جهاز المالك.

## تحديث جارٍ بناءً على قراري المالك D-030 وD-031 — 11 نوفمبر 2026

وافق المالك على **قناتين متوازيتين لرد الاستحقاقات المركزية: رد داخلي مباشر، وتسجيل رد خارجي**، وعلى أن **المراجع صاحب الملاحظة يقبل الرد ويحسم ملاحظته بنفسه** دون توقيع رئيس إضافي لهذا الحسم. حدثت مسودة الخطة وUML وERD إلى `v0.3` لهذين القرارين فقط، وأضيف `PLAN-29` و`PLAN-30` وسجل القرارات. تقارير المراجعة المستقلة وإعادة فحص `v0.2` تخص نسختها السابقة، ولا تُقرأ كأنها راجعت التعديلات الجديدة. استكمال صلاحيات الحسابات ودليل الردود والاستثناءات عند غياب المراجع، واعتماد الصرفية بشكل مستقل، ما زالت أسئلة لاحقة؛ لا SQL أو كود أو تشغيل EGM رسمي بموجب هذا التحديث.
