# نموذج تقرير Goldfish مستقل — غير مُعبأ

> **حالة القالب:** TEMPLATE_ONLY. ملء النموذج يدويًا بواسطة ChatGPT نفسه لا يثبت مراجعة Goldfish مستقلة. لا تحول `NOT_RUN` إلى `PASS` حتى يصل تقرير مراجع فرعي فعلي ويمكن التحقق منه.

## بيانات التشغيل
| الحقل | القيمة عند التنفيذ |
| --- | --- |
| `ReviewRunId` | لم يُنفذ |
| `TargetDocumentPath` | ملف الحزمة |
| `TargetDocumentSha` | SHA المستند المراجع |
| `RepoMainSha` | SHA الأساس |
| `EGMPluginVersion` | الإصدار المثبت |
| `Harness` | بيئة Subagents |
| `FreshContextVerified` | دليل قابل للفحص أو `NO` |
| `ReviewerPersonas` | أسماء الـGoldfish المشغلة |
| `ReadFiles` | قائمة الملفات التي قرأها المراجع |
| `RunStatus` | `NOT_RUN` / `BLOCKED_ENVIRONMENT` / `COMPLETE` |
| `ReportArtifact` | رابط ناتج الجولة |

## الملاحظات
| ID | الدرجة | ملف/سطر/إثبات | سيناريو يكشف الخطأ | الأثر المالي/التقني | الإصلاح والاختبار المقترح | قرار المالك | Issue/PR |
| --- | --- | --- | --- | --- | --- | --- | --- |
| `EGM-01-001` | مثال `QUESTION` | مثال لا يعني نتيجة مراجعة حقيقية | افتراضي | غير مقيّم | يستكمل عند التشغيل | معلّق | لا يوجد |

### مستويات المشكلات
- `BLOCKER`: خلل قد يؤدي لحساب مالي خاطئ أو مصدر غير صحيح أو تكرار صرفية رئيسية أو خرق صلاحية أو حذف أصل.
- `MAJOR`: متطلب/قرار تصميم غير مكتمل، أو علاقة زمن/مبلغ غير قابلة للتحقق قبل التنفيذ.
- `MINOR`: تحسين صيانة أو توضيح لا يمس سلامة الحسابات والضمانات.
- `QUESTION`: قرار أو مرجع قانوني أو سياسة عمل لا يمكن حسمها من المستندات وحدها.

## قرار الجولة
- نتائج الفحص المستقل الفعلية: **لا شيء حتى الآن**.
- المشاكل المانعة المفتوحة: **غير معروف قبل التشغيل**.
- قرارات المالك المطلوبة: **تُستخرج من التقرير**.
- التصميم مُعتمد للبرمجة: **لا**.
- دليل تفعيل Fresh Subagent: **غير موجود حتى الآن**.

لا يُستخدم هذا القالب لتوليد «موافقة آلية»، ولا يغني عن إذن تنفيذ الكود.
